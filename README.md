# 🎓 College Admission FAQ Chatbot

A simple, interactive Natural Language Processing (NLP) chatbot built in Python using Streamlit. This project was developed as an internship project to automate answers to common college admission queries.

## 🚀 Features
* **NLP Pipeline:** Preprocesses text by converting to lowercase, removing punctuation, and tokenizing.
* **Smart Matching:** Uses `TfidfVectorizer` and Cosine Similarity to mathematically find the most relevant FAQ answer based on user input.
* **Confidence Threshold:** Intelligently replies with a fallback message if it doesn't confidently know the answer.
* **Interactive UI:** A clean, scrolling chat interface built entirely in Python using Streamlit.

## 🛠️ Tech Stack
* **Python** 
* **Streamlit** (for the frontend chat UI)
* **Scikit-Learn** (for TF-IDF vectorization and cosine similarity math)
